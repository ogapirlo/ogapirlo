# 宅建まいにち 🏠🔥

Duolingoのしくみを参考にした、宅建士試験対策のAndroidアプリです。
**1日5問・約2分**だけ解けばいいようにして、「とにかく毎日続ける」ことに絞っています。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| 5問レッスン | 問題データからランダムに5問。前回間違えた問題を最大2問混ぜ、残りはまだ解いていない問題から優先して選ぶ |
| 出題形式 | 〇×問題と4択問題（4択は毎回選択肢の順番をシャッフル） |
| 即時フィードバック | 「チェック」で正誤判定し、すぐに解説を表示（Duolingo風の緑/赤パネル） |
| 🔥 ストリーク | 1日1レッスン終えれば、正答数に関係なく連続記録が伸びる。3・7・14・30日…で節目の演出 |
| 🧊 ストリークフリーズ | 休んだ日に自動で使われ、連続記録を守るアイテム（最初に1個、💎50で購入、最大2個） |
| 🎯 1日の目標XP | 10 / 20 / 30 / 50 XPから選択。最後まで解けば必ずXPが入る（完了5＋正解1問ごと1＋全問正解5） |
| 💎 ジェム | レッスン完了・全問正解・目標達成でもらえる |
| 🔁 復習 | 間違えた問題だけで5問レッスン |
| 分野別 | 権利関係 / 宅建業法 / 法令上の制限 / 税・その他 |
| 🔔 リマインダー | 毎日決まった時刻に通知。**その日まだ解いていないときだけ**届く |
| 記録 | 連続記録・最高記録・4週間カレンダー・分野別の正答率 |
| やめる前の引き止め | レッスン途中で閉じようとすると「あと○問で今日の🔥がつきます」 |

## APKの入手（Android Studioがなくても可）

GitHub Actions がプッシュのたびにビルドします。
リポジトリの **Actions → Android build → 最新の実行 → Artifacts** から
`takken-mainichi-debug-apk` をダウンロードし、端末にインストールしてください
（「提供元不明のアプリ」の許可が必要です）。

## 開発

- Kotlin / Jetpack Compose / Material 3、minSdk 26（Android 8.0）
- Android Studio で開くか、`./gradlew assembleDebug`
- ユニットテスト：`./gradlew testDebugUnitTest`（ストリーク・XP・出題ロジック・問題データの整合性）

```
app/src/main/
├── assets/questions.json        問題データ
└── java/com/ogapirlo/takken/
    ├── domain/   出題・ストリーク・XPのルール（Android非依存）
    ├── data/     問題の読み込み、学習記録の保存
    ├── notify/   毎日のリマインダー通知
    └── ui/       画面（ホーム・レッスン・結果・記録・設定）
```

## 問題の追加

`app/src/main/assets/questions.json` に追記するだけで出題対象になります。

```json
{
  "id": "gyo-100",
  "category": "宅建業法",
  "type": "choice",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 0,
  "explanation": "解説",
  "source": "令和5年 問26"
}
```

- `type` は `"ox"`（choices は `["〇", "×"]`、answer は 0=〇 / 1=×）か `"choice"`
- `answer` は正解の選択肢の番号（0始まり）
- `category` は `権利関係` / `宅建業法` / `法令上の制限` / `税・その他`
- 追加後に `./gradlew testDebugUnitTest` を実行するとデータの不備をチェックできます

同梱の67問は、過去問で繰り返し出ている論点をもとに作ったオリジナル問題です。
実際の過去問を入れる場合、個人で使う分には問題ありませんが、アプリを配布するときは
著作権（出題元：一般財団法人 不動産適正取引推進機構）に注意してください。
法改正で正解が変わることもあるので、最新の法令もあわせて確認してください。
